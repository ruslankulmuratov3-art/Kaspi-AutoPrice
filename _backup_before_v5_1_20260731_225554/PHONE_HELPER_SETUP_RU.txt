KASPI AUTOPRICE V5 — ТЕЛЕФОН ПО ОДНОЙ ССЫЛКЕ

1. На Render откройте раздел «Автопилот».
2. Нажмите «Создать ссылку для телефона».
3. Откройте ссылку на телефоне и нажмите «Начать проверку».
4. Страница сначала проверяет CORS одним запросом.
5. Если браузерный запрос разрешён — прогресс идёт на странице.
6. Если CORS запрещён — используйте companion-скрипт с этой же ссылкой:

Windows:
python scripts/local_agent.py --helper-url "ВРЕМЕННАЯ_ССЫЛКА" --fast

Android / Termux:
python scripts/local_agent.py --helper-url "ВРЕМЕННАЯ_ССЫЛКА" --fast

DEV/USR-коды не нужны. Временная ссылка ограничена одним магазином, истекает и может быть отозвана.
Проект не обходит CORS, CAPTCHA, 403/405/429 и не использует cookies личного кабинета.
