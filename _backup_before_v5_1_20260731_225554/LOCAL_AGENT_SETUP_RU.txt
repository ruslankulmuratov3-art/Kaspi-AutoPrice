KASPI AUTOPRICE — НЕСКОЛЬКО ДОВЕРЕННЫХ АГЕНТОВ
==================================================

Как работает:
Render выдаёт разные товары доверенным устройствам. Компьютер или телефон владельца
делает запрос со своего обычного IP, возвращает только проверенный JSON, после чего Render
быстро пересчитывает новые товары и публикует полный XML.

Важно:
- случайный посетитель сайта НЕ становится агентом;
- агент запускается владельцем добровольно и использует секрет LOCAL_AGENT_TOKEN;
- браузер Chrome сам по себе агентом не является; на Android нужен Python/Termux;
- два устройства в одной Wi-Fi сети имеют один внешний IP — ускорение может быть небольшим;
- безопаснее использовать 1–2 устройства с разными интернет-подключениями;
- ниже 3 секунд задержку не ставить.

Что ускорено:
- Render выдаёт задания с временной арендой, поэтому устройства не берут один товар дважды;
- каждые 25 успешных товаров агент запускает быстрый пересчёт;
- быстрый пересчёт обрабатывает только товары с новыми данными;
- XML всё равно формируется полным каталогом;
- при 403/405/429 агент останавливается и соблюдает Retry-After.

Сначала дождись завершения текущего локального расчёта. Затем установи патч.

Render Environment:
LOCAL_AGENT_ENABLED=true
LOCAL_AGENT_TOKEN=<один длинный секрет для доверенных устройств>
KASPI_PUBLIC_OFFERS_ENABLED=false
LOCAL_AGENT_BATCH_SIZE=25
LOCAL_AGENT_FLUSH_EVERY=25
LOCAL_AGENT_LEASE_MINUTES=15

Первый компьютер:
$env:RENDER_BASE_URL="https://kaspi-autoprice.onrender.com"
$env:LOCAL_AGENT_TOKEN="<тот же секрет>"
$env:LOCAL_AGENT_ID="office-pc"
$env:AGENT_DELAY_SECONDS="4"
$env:AGENT_MIN_DELAY_SECONDS="3"
.\.venv\Scripts\python.exe scripts\local_agent.py --fast

Второй компьютер/телефон:
Использует тот же LOCAL_AGENT_TOKEN, но другой LOCAL_AGENT_ID, например owner-phone.

$env:LOCAL_AGENT_ID="owner-phone"
.\.venv\Scripts\python.exe scripts\local_agent.py --fast

Остановить: Ctrl+C.
