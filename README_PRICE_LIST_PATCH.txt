Kaspi price-list patch

Что меняется:
- Кнопка автоцены больше НЕ отправляет цену напрямую в /products/import.
- Вместо этого сайт рассчитывает новую цену и скачивает Excel-прайс-лист Kaspi.
- Безопаснее всего выбрать шаблон .xlsx, скачанный из кабинета Kaspi: тогда сайт меняет только колонку price и сохраняет SKU/model/brand/PP1-PP5/preorder.
- Массовая кнопка для всех товаров возвращена в раздел «Товары»: она тоже скачивает Excel, а не отправляет в Kaspi API.

После установки:
1) pip install openpyxl
2) Перезапусти сервер.
3) В Kaspi кабинете скачай свой прайс-лист .xlsx.
4) В карточке товара или на странице «Товары» выбери этот файл как шаблон.
5) Нажми скачать автопрайс.
6) Загрузи скачанный файл обратно в Kaspi через Управление товарами → Прайс-лист.
