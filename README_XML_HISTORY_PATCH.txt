Kaspi XML History Patch

Что добавлено:
1. История версий XML: когда создан файл, сколько товаров, сколько цен изменено.
2. Детали по выбранной версии XML: SKU, название, старая цена, цена в XML, разница, причина.
3. Журнал запросов XML: когда кто-то открыл /kaspi-feed/{store_id}.xml, IP, User-Agent, версия XML.
4. Страница /xml-history.
5. Блоки истории на странице /automation.

Важно:
- Это показывает, когда XML был создан и когда ссылка была запрошена.
- Kaspi не отправляет callback “цены применены”, поэтому финальный статус принятия прайса смотрите в кабинете Kaspi → история загрузок.

Установка:
1. Скопировать файлы патча в проект с заменой.
2. git add .
3. git commit -m "Add XML audit history"
4. git push
5. Render сам перезапустит деплой.
