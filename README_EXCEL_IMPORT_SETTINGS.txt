Патч: импорт товаров из Kaspi Excel + неподтверждённые товары + настройки автоцены.

Что добавлено:
1) Новый блок на странице /products: «Импорт товаров из Kaspi Excel».
   Сюда можно загрузить ACTIVE.xlsx / прайс-лист из Kaspi.
   Это НЕ меняет цены в Kaspi, а только добавляет/обновляет товары в локальной базе.

2) Раздел «Неподтверждённые товары».
   Товары после Excel-импорта сначала выключены от автоцены, пока не указаны лимиты.

3) Массовая настройка лимитов:
   - минимум ниже текущей цены на %
   - максимум выше текущей цены на %
   - себестоимость как % от цены
   - шаг снижения ниже конкурента
   - максимальное изменение за запуск
   - минимальная маржа

4) Настройки в карточке товара:
   можно менять SKU, URL, текущую цену, остаток, минимум, максимум, себестоимость,
   стратегию, шаг, процент изменения за раз, игнорируемых продавцов.

5) Массовый автопрайс теперь берёт только подтверждённые товары:
   auto_pricing_enabled=True, status=active, min_price>0, max_price>0.

Установка:
1. Останови сервер Ctrl+C.
2. Распакуй zip.
3. Скопируй содержимое папки патча в проект с заменой.
4. Установи openpyxl: .\.venv\Scripts\python.exe -m pip install openpyxl
5. Запусти сервер заново.
