Kaspi history fix patch

Что исправляет:
- Excel-прайс больше не отображается как будто цена уже изменилась в Kaspi.
- Дашборд показывает Excel-файлы в блоке «Прайс-листы и уведомления».
- «История цен» показывает только подтверждённые изменения.
- Добавлена кнопка «Сбросить тестовую историю».
- Если случайно загрузить .xlsx в блок «Импорт CSV», сайт покажет понятную ошибку вместо utf-8 traceback.

После установки:
1) Перезапусти сайт.
2) Открой /history и нажми «Сбросить тестовую историю», если хочешь убрать старые тестовые записи.
3) Для автопрайса используй только блок «Массовый автопрайс для всех товаров» на странице /products.
