Kaspi Safe Multi Store Patch

Что изменено:
1. Автопрайс теперь требует полный ACTIVE.xlsx из Kaspi.
   Минимальные Excel-файлы на один товар больше не создаются, чтобы не рисковать снятием остальных товаров с продажи.

2. Добавлен переключатель магазина на странице /products.
   Импорт, массовые лимиты и массовый автопрайс работают только по выбранному магазину.

3. Страница /products стала понятнее:
   - Импорт ACTIVE.xlsx
   - Массовые лимиты
   - Массовый автопрайс
   - Неподтверждённые товары
   - Ручное добавление
   - CSV спрятан ниже как отдельный инструмент

4. Кнопка скачивания Excel больше не зависает на “Работаю...” после скачивания.

5. Дизайн обновлён: более аккуратные блоки, анимации, чистые тексты.

Как поставить:
1) Остановить сайт: Ctrl+C
2) Распаковать ZIP и скопировать файлы в проект с заменой.
3) Запустить сайт обратно:
   $env:PYTHONPATH="."; .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
4) Обновить страницу Ctrl+F5.
