Kaspi AutoPrice — batch/progress patch

Что добавлено:
1. Галочки выбора товаров в списке.
2. Выбор показанных товаров одним кликом.
3. Расчёт Excel только по выбранным товарам.
4. Расчёт Excel по количеству товаров: 50, 100, 200 и т.д.
5. Массовые лимиты можно применить к выбранным товарам или первым N товарам.
6. Поиск + фильтр: все / готовые / нужно настроить / активные.
7. Настройка количества строк в таблице.
8. Визуальный прогресс в процентах при подготовке Excel.
9. Исправлен шаг поля “Ниже конкурента на, ₸”: теперь можно ставить 1, 2, 3.

Важно:
Файл на выходе всё равно полный ACTIVE.xlsx. Просто цены меняются только у выбранных SKU или указанного количества товаров. Это безопаснее, чем делать маленький Excel на один товар.
