Kaspi AutoPrice v5.1 — отчёт исправлений

Исправлено:
- SQLite database is locked при INSERT xml_feed_versions на 99.9%;
- XML и завершение AutopilotJob используют одну Session и одну транзакцию;
- SQLite: WAL, busy_timeout 60 секунд, foreign_keys, synchronous NORMAL;
- параллельный helper XML сериализован по магазину;
- ошибки SQL/XML сокращаются до понятного сообщения;
- сохранённый cursor позволяет продолжить с последнего товара;
- ETA и количество оставшихся товаров обновляются каждые 3 секунды;
- очередь скрывается, когда равна нулю;
- NULL в результатах отображается как тире;
- helper routes включены;
- старые пункты Устройства/Админ/регистрация отсутствуют в меню и legacy API выключен;
- Manrope и Unbounded подключены в общей базе шаблонов.

Проверка:
- compileall: OK
- pytest: 25 passed
- новый тест воспроизводит запись XML внутри активной SQLite-транзакции.

После установки:
1. Запустить migrate.py.
2. Запустить pytest.
3. Запустить сайт.
4. На ошибочном задании нажать «Продолжить с сохранённого места».
5. Проверить создание полного XML.
6. Выполнить git push — только после этого Render получит те же изменения.
