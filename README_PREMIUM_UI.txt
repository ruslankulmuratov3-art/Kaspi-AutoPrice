Kaspi Premium UI Patch

Что меняет:
- Полностью новый премиальный интерфейс: glassmorphism, аккуратная сетка, современные отступы, плавные анимации.
- Страница /stores стала страницей выбора магазина.
- Карточки магазинов: логотип, название, город, Merchant ID, количество товаров, готовые/неподтверждённые товары, статус и кнопка "Перейти".
- Добавлена панель редактирования магазина: название, ID, город, токен, активность.
- Страницы dashboard, products, product_detail, history, login и admin приведены к единому стилю.
- Существующая логика автопрайса, импорта ACTIVE.xlsx и генерации полного Excel сохранена.

Как поставить:
1) Остановить сервер Ctrl+C.
2) Распаковать архив в Downloads.
3) Скопировать содержимое папки патча в корень проекта с заменой.
4) Запустить сервер.
5) В браузере нажать Ctrl+F5.

Важно:
Этот патч меняет интерфейс и UX. Рабочие функции не удаляются.
